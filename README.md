# しりとりファイター

Google Apps Script (GAS) を利用して開発された、小学生向けのしりとり対戦Webアプリケーションです。休み時間に児童が楽しみながら語彙力や瞬発力を養うことを目的としています。

## 概要

このアプリは、Webブラウザ上で動作するしりとり対戦ゲームです。GIGAスクール端末（Chromebookなど）があれば、どの学級でも気軽に利用できます。プレイヤーは自分の名前とキャラクターを設定し、相手プレイヤーとHPを削り合うしりとりバトルを繰り広げます。

## 特徴

-   **Webブラウザで動作**: 特定のOSやデバイスに依存せず、インターネット接続があればどこでもプレイ可能です。GIGAスクール端末での利用に最適です。
-   **シンプルなルール**: 基本的なしりとりのルールに基づいているため、低学年から高学年まで、誰もが簡単に楽しめます。
-   **カスタマイズ可能な設定**: プレイヤー名、対戦キャラクター、初期HP、タイマーの制限時間などを自由に設定でき、学年や習熟度に合わせて調整可能です。
-   **直感的なUI**: 小学生にも分かりやすいデザインと操作性で、迷わずゲームに参加できます。

## インストール（セットアップ）方法

本アプリはGoogle Apps Script（GAS）として提供されます。以下の手順でGoogleアカウントにデプロイすることで利用可能になります。

1.  **Google スプレッドシートの準備**:
    *   Google ドライブを開き、「新規」>「Google スプレッドシート」を選択して新しいスプレッドシートを作成し、開きます。
    *   ※スプレッドシート自体はアプリの動作には直接関係ありませんが、GASプロジェクトを作成するための器として利用します。

2.  **Apps Script エディタの起動**:
    *   開いたスプレッドシートのメニューから「拡張機能」>「Apps Script」を選択します。新しいタブでスクリプトエディタが開きます。

3.  **コードのコピー**:
    *   スクリプトエディタに初期表示されている `コード.gs` ファイルの内容をすべて削除し、提供されている `code.gs` ファイルの内容をコピー＆ペーストします。
    *   次に、スクリプトエディタの左側のファイル一覧で「ファイル」アイコン > 「HTML」を選択します。ファイル名には「`index`」と入力し、「OK」をクリックします。
    *   新しく作成された `index.html` ファイルの内容をすべて削除し、提供されている `index.html` ファイルの内容をコピー＆ペーストします。

4.  **プロジェクトの保存**:
    *   スクリプトエディタ上部のフロッピーディスクアイコン（プロジェクトを保存）をクリックして、変更を保存します。プロジェクト名が未設定の場合は、ここで「しりとりファイター」などの名前を設定できます。

5.  **ウェブアプリケーションとしてデプロイ**:
    *   スクリプトエディタの右上の「デプロイ」ボタン > 「新しいデプロイ」を選択します。
    *   「デプロイの種類を選択」をクリックし、「ウェブアプリ」を選択します。
    *   デプロイの設定画面で以下を設定します。
        *   **説明**: `しりとりファイター` など、任意のデプロイの説明を入力します。
        *   **実行者**: `自分` を選択します。
        *   **アクセスできるユーザー**: `全員` を選択します。
            *   **【注意】**: 学校内で利用する場合、セキュリティ上の理由から `組織内のユーザー` を選択することも可能です。その場合、アクセスにはGoogleアカウントでのログインが必要になります。必要に応じて選択してください。
    *   「デプロイ」ボタンをクリックします。
    *   **承認が必要な場合**: 初回デプロイ時には、Googleアカウントの承認プロセスが表示されることがあります。「アクセスを承認」をクリックし、指示に従って承認を完了してください。
    *   デプロイが完了すると、「ウェブアプリのURL」が表示されます。このURLが本アプリのアドレスになります。

6.  **URLの共有**:
    *   表示された「ウェブアプリのURL」をコピーし、児童のGIGAスクール端末等に共有してください。これで児童がアプリにアクセスできるようになります。

## 遊び方

1.  **アプリにアクセス**: 共有されたウェブアプリのURLをブラウザで開きます。
2.  **セットアップ画面**:
    *   プレイヤー1とプレイヤー2の名前を入力します（ニックネーム可）。
    *   好きなキャラクターアイコンを選択します。
    *   ゲームの初期HP（ライフ）と、一単語あたりのタイマー制限時間（秒）を設定します。
    *   「ゲーム開始！」ボタンをクリックします。
3.  **ゲーム開始**:
    *   画面に表示された最初のお題の文字（例：「あ」から始まる言葉）を確認します。
    *   自分のターンになったら、お題の文字から始まる言葉を入力欄に打ち込み、「攻撃！」ボタンをクリックして送信します。
        *   入力はひらがな、カタカナで行ってください。自動的にひらがなに変換されます。
        *   「ん」で終わる言葉を入力したり、一度使われた言葉を再度入力したりすると、失敗となり相手の攻撃になります。
        *   タイマーが0になるまでに言葉を入力できないと、ペナルティとしてダメージを受けます。
4.  **ターン交代と攻撃**:
    *   正しい言葉を入力すると相手にダメージを与え、ターンが交代します。次のプレイヤーは、直前の言葉の最後の文字から始まる言葉を考えます。
5.  **勝敗**:
    *   相手プレイヤーのHPを先に0にした方が勝利となります。
    *   ゲーム終了後、「もう一度！」ボタンで新しいゲームを開始できます。
