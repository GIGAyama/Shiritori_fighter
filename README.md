# ⚡ しりとりファイター

ことばで戦うしりとり対戦Webアプリです。小学生が休み時間に楽しみながら語彙力や瞬発力を養うことを目的としています。ふたりでの対戦はもちろん、コンピュータとのひとり対戦や、マイクを使った音声入力にも対応しています。

## 特徴

- **PWA対応**: ChromeやEdgeから「アプリとしてインストール」でき、ホーム画面から起動可能。一度読み込めばオフラインでも遊べます（静的ホスティング時）。
- **音声入力対応** 🎤: マイクボタンを押して話すだけで言葉を入力できます。文字入力が苦手な低学年でも遊べます（Chrome系ブラウザ、要インターネット接続）。
- **ひとりでも遊べる**: コンピュータ対戦モードを搭載。「やさしい・ふつう・つよい」の3段階の強さを選べます。
- **どんな端末でも快適**: スマートフォン・タブレット・Chromebook・PCの縦横どちらの画面でも、メインのゲーム領域が広く表示されるレスポンシブ設計です。
- **ゲームらしい演出**: 効果音（音源ファイル不要のWebAudio合成）、ダメージポップアップ、画面シェイク、ヒットエフェクト、ターン開始バナー、紙吹雪など。
- **入力はなんでもOK**: ひらがな・カタカナ・ローマ字入力を自動でひらがなに変換します（外部ライブラリ不要）。
- **カスタマイズ可能**: プレイヤー名、キャラクター、初期HP（30/50/100）、制限時間（10/20/30秒）を選べます。

## ルール

1. 表示された文字から始まる言葉を、制限時間内に入力（または音声で発言）します。
2. 正しい言葉を入力すると相手に **文字数ぶんのダメージ** を与えます。拗音（ゃゅょ）や長音（ー）は1文字につき **+2のボーナスダメージ**！
3. 時間切れになると自分が5ダメージを受けます。
4. 「ん」で終わる言葉を言ったら即負け。一度使われた言葉は使えません。
5. 先に相手のHPを0にした方の勝ちです。

## インストール（デプロイ）方法

### 方法1: GitHub Pages（推奨・PWA対応）

PWA機能（アプリとしてのインストール・オフライン動作）を使うにはこちらを利用してください。

1. このリポジトリをGitHubでフォーク（または自分のリポジトリにコピー）します。
2. リポジトリの **Settings > Pages** を開き、「Source」を `Deploy from a branch`、ブランチを `main`（フォルダは `/root`）に設定して保存します。
3. 数分後に `https://<ユーザー名>.github.io/<リポジトリ名>/` でアプリが公開されます。
4. このURLをChromeで開くと、アドレスバーまたはアプリ内ヘッダーの「📲 インストール」ボタンからアプリとしてインストールできます。
   - スマートフォン（Android/Chrome）: メニューから「ホーム画面に追加」
   - iPhone/iPad（Safari）: 共有メニューから「ホーム画面に追加」

### 方法2: Google Apps Script（GAS）

学校のGoogle Workspace環境で組織内限定公開したい場合はこちら。GAS上でもゲームは全機能動作しますが、**PWA機能（インストール・オフライン動作）は利用できません**（GASの仕組み上、Service Workerが動作しないため）。

1. **Apps Script プロジェクトの作成**: [script.google.com](https://script.google.com) で「新しいプロジェクト」を作成します。
2. **コードのコピー**:
   - `コード.gs` の内容をすべて削除し、このリポジトリの `code.gs` の内容を貼り付けます。
   - 「ファイル」横の「＋」>「HTML」でファイル名 `index` のファイルを作成し、`index.html` の内容を貼り付けます。
3. **デプロイ**: 右上の「デプロイ」>「新しいデプロイ」>「ウェブアプリ」を選択します。
   - 実行者: `自分` / アクセスできるユーザー: `全員`（または `組織内のユーザー`）
4. 表示された「ウェブアプリのURL」を児童の端末に共有してください。

## 遊び方

1. **モードを選ぶ**: 「ふたりで対戦」か「コンピュータと対戦」を選びます。
2. **セットアップ**: 名前を入力し、キャラクターを選び、HPと制限時間を設定して「バトルスタート！」。
3. **バトル**:
   - 画面中央の文字から始まる言葉を入力して「こうげき！」。
   - 🎤 ボタンを押すと声で入力できます（初回はマイクの許可が必要です）。
   - カタカナ・ローマ字で入力しても自動でひらがなに変換されます。
4. **勝敗**: 相手のHPを先に0にしたら勝ち！ リザルト画面では使った言葉の数や最大ダメージも確認できます。

## 技術メモ

- 依存ライブラリなしの単一 `index.html`（＋PWA用の `manifest.webmanifest` / `sw.js` / `icons/`）で構成されています。ビルド不要です。
- かな変換（カタカナ→ひらがな、ローマ字→ひらがな）は内蔵の変換器で行うため、オフラインでも動作します。
- 効果音はWebAudio APIでリアルタイム合成しており、音声ファイルを持ちません。
- 音声入力はWeb Speech API（`SpeechRecognition`）を使用します。非対応ブラウザではマイクボタンは表示されません。
- `prefers-reduced-motion` を尊重し、動きを抑えた表示にも対応しています。
